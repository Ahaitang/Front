Neuroimmune App

神经免疫疾病随访小程序  |  Uni-app + Vue 3 + Vuex  |  目标平台：微信小程序 / H5

项目简介

神经免疫疾病随访系统的患者端小程序，供患者填写随访信息、查看病历、绑定医生等。支持微信小程序和 H5 两端发布。

技术栈

技术说明
Uni-app（Vue 3）跨平台框架
Vuex状态管理（项目现用）
JavaScript主要语言
uni.request网络请求

开发环境

推荐使用 HBuilderX（App 开发版）进行开发，内置 uni-app 运行环境，无需额外配置。
# CLI 方式安装依赖
npm install

# H5 开发预览
npm run dev:h5

# 微信小程序开发
npm run dev:mp-weixin

项目结构

neuroimmune-app/
├── api/              # 接口请求封装
├── pages/            # 页面目录
│   ├── index/        # 首页
│   ├── login/        # 登录/注册
│   ├── patient/      # 患者信息
│   ├── followup/     # 随访记录
│   └── ...
├── store/            # Vuex 状态管理
├── common/           # 公共工具
├── components/       # 公共组件
├── static/           # 静态资源
├── App.vue
├── main.js
├── pages.json        # 页面配置
└── manifest.json     # 应用配置

支持疾病类型

  • MS（多发性硬化）
  • NMOSD（视神经脊髓炎谱系疾病）
  • MG（重症肌无力）
  • MOGAD（MOG 抗体相关疾病）
  • 自身免疫性脑炎
  • GBS（吉兰-巴雷综合征）
  • CIDP（慢性炎症性脱髓鞘性多发性神经病）

API 配置

接口基础地址配置在 api/ 目录中，开发环境指向 http://localhost:8080，生产环境使用 https://api.ahaitang.top/api。

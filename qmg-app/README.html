QMG App

重症肌无力定量评分小程序  |  Uni-app + Vue 3 + TypeScript + Pinia  |  微信小程序 / H5

项目简介

重症肌无力定量评分系统（Quantitative Myasthenia Gravis Score System）的患者/医生端小程序，实现 13 项临床指标的量化评分、病情追踪与报告展示。

评分标准

≤ 9
轻度
10 – 18
中度
> 18
重度

总分范围 0 – 39 分，基于 13 项临床指标评估。

技术栈

技术说明
Uni-app跨平台框架（Vue 3 + Composition API）
TypeScript类型约束
Pinia状态管理
Vite构建工具

QMG 算法实现

计时项

指标阈值（0/1/2/3分）
复视/眼睑下垂61 / 11 / 1 秒
上肢抬起240 / 90 / 10 秒
下肢抬起/抬头100 / 31 / 1 秒

测力项（握力）

性别0分1分2分3分
男性≥ 45 kg≥ 15 kg≥ 5 kg< 5 kg
女性≥ 30 kg≥ 10 kg≥ 5 kg< 5 kg

其他指标

  • 肺活量预计值%（阈值: 80 / 65 / 50）
  • 构音障碍计数（1–50 范围映射）

功能特性

  • 身份选择：患者入口 / 医生入口
  • 分步测评表单（基础信息 → 计时项 → 测力项 → 激素用量）
  • 实时得分计算与显示
  • QMG 总分趋势图表（需至少 2 条历史记录）
  • 激素用量曲线（标注达标区）
  • 历史记录查看

开发

# 安装依赖
npm install

# H5 开发预览
npm run dev:h5

# 微信小程序开发
npm run dev:mp-weixin

# 构建
npm run build
推荐使用 HBuilderX（App 开发版）进行开发，可直接运行到微信小程序模拟器。

# QMG评分小程序

重症肌无力定量评分系统 (Quantitative Myasthenia Gravis Score System)

## 项目简介

基于 Vue3 + TypeScript + Uni-app 开发的QMG评分小程序，用于评估重症肌无力患者的病情严重程度。

## 技术栈

- **框架**: Vue 3 (Composition API)
- **语言**: TypeScript
- **跨平台**: Uni-app
- **状态管理**: Pinia
- **构建工具**: Vite

## 功能特性

### 1. QMG算法实现

实现了13项指标的算分逻辑：

- **计时项**:
  - 复视/下垂（阈值: 61/11/1秒）
  - 上肢抬起（阈值: 240/90/10秒）
  - 下肢与抬头（阈值: 100/31/1秒）

- **测力项**:
  - 握力映射（含性别逻辑）
    - 男性: ≥45/15/5kg
    - 女性: ≥30/10/5kg

- **肺功能/计数**:
  - 肺活量预计值%（阈值: 80/65/50）
  - 构音障碍计数（1-50范围映射）

### 2. 分步测评表单

- 基础信息录入（姓名、性别、住院号、手机号）
- 症状计时录入（实时显示得分）
- 临床观察录入（实时计算）
- 激素用量录入

### 3. 双达标报告

- QMG总评分展示（满分39分）
- QMG总分趋势图表
- 激素用量曲线（标注达标区）
- 历史记录查看

## 使用说明

1. **身份选择**: 启动应用后，选择"患者入口"或"医生入口"
2. **基础信息**: 填写患者基本信息
3. **症状计时**: 输入各项计时数据，系统自动计算得分
4. **临床观察**: 输入握力、肺活量、构音障碍等数据
5. **激素用量**: 记录激素使用量
6. **查看报告**: 完成测评后查看总评分和趋势图表

## 评分标准

- **总分范围**: 0-39分
- **轻度**: ≤9分
- **中度**: 10-18分
- **重度**: >18分

## 注意事项

1. 握力计算需要根据患者性别使用不同的阈值
2. 所有输入值会实时计算并显示对应得分
3. 测评数据会自动保存到历史记录
4. 图表展示需要至少2条历史记录

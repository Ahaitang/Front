QMG Admin

重症肌无力定量评分管理后台  |  Vue 3 + TypeScript + Vite + Element Plus

功能特性

  • ✓ 用户登录/登出（会话级别存储）
  • ✓ 患者管理（增删改查、批量导入）
  • ✓ 问卷记录管理（查询、删除、详情查看）
  • ✓ 医生管理
  • ✓ 数据统计仪表盘
  • ✓ 响应式布局

技术栈

技术说明
Vite下一代前端构建工具
Vue 3渐进式 JavaScript 框架
TypeScriptJavaScript 的超集
Element Plus基于 Vue 3 的 UI 组件库
Pinia + Persistedstate状态管理（sessionStorage 级别）
AxiosHTTP 客户端

快速开始

# 安装依赖（推荐 pnpm）
pnpm install

# 启动开发服务器（http://localhost:3000）
pnpm dev

# 生产构建（base: '/qmg/'）
pnpm build

# 预览构建结果
pnpm preview

路由说明

路径页面需要登录
/login登录页面否
/dashboard仪表盘是
/patients患者管理是
/questionnaires问卷记录管理是
/doctors医生管理是

API 规范

  • 所有 API 请求使用 POST 方法
  • 基础路径：/api（开发环境代理到 http://localhost:8080）
  • 后端返回格式：{ code: 1, msg: '...', data: ... }（code=1 表示成功）

数据持久化

使用 pinia-plugin-persistedstate 配置为 sessionStorage 级别：关闭标签页后登录状态自动清除，刷新页面时自动恢复。

Neuroimmune Admin

神经免疫疾病随访管理后台  |  Vue 3 + TypeScript + Vite + Element Plus

技术栈

技术说明
Vue 3 + Composition API渐进式 JavaScript 框架
TypeScript类型安全
Vite 7构建工具
Element PlusUI 组件库
Vue Router 4路由管理
AxiosHTTP 请求封装

开发

# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 生产构建（base: '/neuro/'）
npm run build
注意： 构建时 vite.config.ts 中 base 设置为 '/neuro/'，确保与 Nginx 路由匹配。 开发代理：/api → http://localhost:8080

认证说明

  • 使用 localStorage 存储 Token（设计选择，无 Pinia 状态管理）
  • API 请求通过 axios 拦截器自动注入 Authorization 头
  • 所有接口请求使用 POST 方法
  • 后端返回格式：{ code: 200, msg: '...', data: ... }
